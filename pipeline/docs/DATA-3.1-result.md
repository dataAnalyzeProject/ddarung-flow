## 5. 최종 채택 모델 및 구조 근거

1. **알고리즘 채택 (트리 모델 HistGradientBoosting)**:
   - 모든 검증 알고리즘 중 Brier Score **`0.0715` (1위)** 및 Calibration Error **`0.0165` (1위)**로 확률 예측 오차가 가장 적고 보정 품질이 우수함.
2. **구조 채택 (단일 통합 모델 Global Model)**:
   - Horizon별 4개 전용 모델(평균 Brier `0.0711`)과 통합 모델(`0.0715`)의 차이가 **불과 `0.0004`**로 매우 미미함.
   - 단일 모델 채택 시 아티팩트 파일 1개만 관리하면 되므로 Airflow 및 API 파이프라인의 **엔지니어링 운영 복잡도와 시스템 장애 위험을 4배 감소**시킴.
