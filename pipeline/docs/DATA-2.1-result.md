- DATA-2.1은 승인 작업서대로 `train/test` 시간순 8:2 분할만 사용한다.
- `validation` 분할과 모델 보정은 DATA-3.1 범위로 넘긴다.
- 최종 DATA-2.1 학습 기준선은 `exclude_2022`로 승인한다. 동일 test에서
  `include_2022`보다 통계 기준선의 Brier·calibration·accuracy가 20개
  H×수량 조합 모두 일관되게 좋았다. 일부 deficit recall의 상충은 아래 전체
  표에 그대로 남긴다.
