# FE 2-1 PC 메인 화면 시안

실제 지도, 따릉이 API, 로그인, 예측 계산을 연결하지 않은 PC 화면용 디자인 시안입니다.
시안 1~6은 모두 `data/mockData.js`의 같은 문구와 숫자를 사용하며 최종 선택안은 시안 6입니다.

## 시안 비교표

| 시안 | 컴포넌트 | 특징 | 상태 |
| --- | --- | --- | --- |
| 1 | `Draft1MapFirst` | 큰 지도 위에 검색과 추천 결과를 겹쳐 표시 | 보존 |
| 2 | `Draft2MapAndList` | 검색, 지도, 대여소 목록을 좌우 영역으로 분리 | 보존 |
| 3 | `Draft3SearchFirst` | 검색 영역을 먼저 강조하고 카드 결과와 지도 표시 | 보존 |
| 4 | `Draft4Dashboard` | 어두운 정보 대시보드에서 지도와 예측 목록 표시 | 보존 |
| 5 | `Draft5JourneyTimeline` | 추천 대여소를 이동 경로 타임라인으로 표시 | 보존 |
| 6 | `Draft6CardCanvas` | 큰 숫자 카드와 지도 타일을 나란히 배치 | **최종 선택** |

시안 6은 대여소별 자전거 수와 가능성을 빠르게 비교할 수 있고, 출발지·목적지·이동수단·예상시간을 한 영역에서 확인할 수 있어 최종안으로 선택했습니다.

## 화면 상태표

| 화면 상태 | 반드시 보일 내용 | 사용자가 할 수 있는 일 |
| --- | --- | --- |
| 메인 | 출발지, 목적지, 이동수단, 예상시간 | 입력값 확인 후 예측 버튼 누르기 |
| 로그인 필요 | 로그인이 필요하다는 안내 | 로그인 화면으로 이동 |
| 로그인 후 | 이전 입력값과 다시 예측 버튼 | 입력값을 확인하고 직접 다시 예측 |
| 결과 | 대여소명, 서로 다른 도착시각, 높음·중간·낮음 | 대여소 결과 비교 |
| 결과 없음 | 조건에 맞는 결과가 없다는 안내 | 입력 수정 |
| 오류 | 결과를 불러오지 못했다는 안내 | 다시 시도 |

## 공통 문구 기준

- 안내: `도착할 때 빌릴 수 있는 따릉이를 미리 확인하세요.`
- 로그인: `예측을 실행하려면 로그인해 주세요. 로그인 후 입력값을 확인하고 다시 예측할 수 있습니다.`
- 결과: `대여소별 예상 도착시간 기준 대여 가능성`
- 가능성: `높음`, `중간`, `낮음`

## 테스트

`MainScreenDrafts.test.jsx`에서 여섯 컴포넌트가 공통 대여소명, 서로 다른 도착시간, 높음·중간·낮음을 렌더링하는지 확인합니다. 최종 시안 6은 출발지, 목적지, 예상시간, 예측 버튼, 로그인 안내도 추가로 확인합니다.
